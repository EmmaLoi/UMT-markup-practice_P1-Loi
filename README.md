# Flora

Responsive landing page for a flower shop created as a part of HTML/CSS practice.

## Technologies

- HTML5
- CSS3
- Flexbox
- Responsive design
- SVG sprites
- AOS animations

## Features

- Semantic HTML structure
- Adaptive layout for mobile, tablet and desktop
- Optimized images
- Mobile menu
- Hover and focus states
